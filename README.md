A robot's two-line confession. Line one owns one exact mistake — the car keys went into the freezer, because cold preserves things. Line two draws the lesson from it: preservation is not the same as accessibility, so from now on the keys stay where hands can find them, not where the ice cream lives. The program writes the two lines to `/output/entry.txt`.
